## 🌟 أبرز مميزات النظام

### 1. إدارة المخزون والمحركات (Engines & Inventory)
- تسجيل سريع للمحركات بقاعدة الـ 4 حقول الأساسية (رقم المكنة، الماركة/الموديل، تكلفة الجملة، وسعر البيع).
- نموذج أكورديون للمواصفات الإضافية (سنة الصنع، الفتيس، المشال والمصاريف الإضافية).
- **أرشفة أوراق الإفراج الجمركي محلياً 100%**: حفظ صور مستندات الإفراج بدقة عالية داخل IndexedDB محلياً على الجهاز لحماية سرية البيانات وتجنب استهلاك كوتا السحابة.

### 2. نقطة البيع السريعة (High-Density POS)
- كاشير فوري ببحث ذكي ورقم المكنة والباركود مع تركيز تلقائي (`autoFocus`).
- زر **"كاش فوري (دفع كامل وطباعة)"** بنقرة واحدة لإنهاء 70%+ من عمليات البيع النقدية في ثانية واحدة.
- **ضبط صارم للبيع الآجل**: منع إصدار أي فاتورة على الأجل أو بدفع جزئي دون ربطها بعميل مسجل، مع زر فوري لتسجيل العميل الجديد وحفظ الفاتورة باسمه.
- دعم إدخال رقم شاسيه السيارة وضمان المحرك.
- تصفير فوري وتلقائي لكارت المبيعات بعد كل عملية بيع.

### 3. الفواتير والطباعة المزدوجة (Dual Printing Modes)
- **إيصال كاشير حراري 80مم**: دعم كامل لطابعات الإيصالات (POS Thermal Receipts) بتنسيق طولي ومضغوط للمحلات.
- **فاتورة رسمية A4**: طباعة ضريبية ورسمية كاملة بجداول وتفاصيل الضمان والبيانات القانونية.
- **نظام المرتجعات**: إمكانية إرجاع أي محرك مسترجع (↺) مع إعادة حالته للمخزن وتحديث الخزينة وحساب العميل فوراً.
- **خصومات ما بعد البيع (🏷️)**: إمكانية تطبيق خصم إضافي على أي فاتورة سارية وتعديل المديونية تلقائياً.

### 4. التحليلات المالية ورأس مال المخزن (Business Analytics)
- **تقييم المخزن بسعر الجملة**: حساب رأس المال الفعلي المخزن بالمستودع على أساس تكلفة الشراء والمصاريف الإضافية.
- **حساب الوارد الشهري بالجملة**: حساب تكلفة المحركات الجديدة التي دخلت المستودع خلال كل شهر مالي.
- **أرباح ومبيعات الشهر**: استخراج صافي الأرباح وهوامش الربح الفعلية وتكلفة البضاعة المباعة (COGS).
- **توزيع رأس المال حسب الماركة**: رسوم بيانية توضح توزيع عدد المحركات ورؤوس الأموال المستثمرة لكل ماركة سيارات.

### 5. النسخ الاحتياطي والأمان (Data & Backups)
- **نسخ احتياطي أسبوعي ذكي**: تنبيه آلي في الشريط العلوي عند مرور 7 أيام بدون نسخ.
- **تصدير JSON شامل بنقرة واحدة**: يحتوي على كافة سجلات المحركات، الفواتير، العملاء، الموردين، والحركات المالية، بالإضافة لصور الإفراجات المحلية مشفرة Base64.
- **تصدير إكسيل عربي معتمد (UTF-8 BOM)**: تصدير كافة الجداول إلى ملفات CSV تدعم الفتح المباشر في Microsoft Excel دون تشويه الأحرف العربية (`\uFEFF`).
- **أمان الحسابات و PIN**: تسجيل دخول محمي برمز PIN من 4 أرقام، يدعم الكيبورد الفعلي ولوحة الأرقام.

- **نظام التشغيل**: Windows 10/11 أو Linux (Ubuntu/Debian/Arch)

## 🚀 التشغيل في بيئة التطوير

```bash
# تثبيت الحزم
npm install

# تشغيل واجهة الويب فقط (Vite)
npm run dev

# تشغيل تطبيق الديسكتوب (Electron + Vite)
npm run dev:electron
```

---

## 📦 البناء واستخراج حزم التثبيت (Production Builds)

```bash
# فحص الكود والأخطاء
npm run lint

# بناء ملفات الويب والـ Electron
npm run build:all

# إنشاء حزمة تثبيت لينكس (AppImage + .deb)
npm run dist:linux

# إنشاء حزمة تثبيت ويندوز (.exe Installer)
npm run dist:win

# إنشاء جميع الحزم معاً
npm run dist:all
```

الملفات المُجمعة ستجدها داخل مجلد `release/`.

## ⚙️ النشر الآلي عبر GitHub Actions (CI/CD)

المشروع مزود بـ Workflow متكامل داخل `.github/workflows/build.yml`:
1. يتم فحص الكود والأنماط والتأكد من سلامة الـ TypeScript.
2. يتم بناء نسختين كاملتين بشكل متوازي:
   - **Linux**: ملف `Al-Aseel Motors.AppImage` وحزمة `deb`.
   - **Windows**: مثبت `Al-Aseel Motors Setup.exe`.
3. عند عمل Release على GitHub، يتم رفع الحزم الناتجة تلقائياً كملفات تحميل (Release Assets).
